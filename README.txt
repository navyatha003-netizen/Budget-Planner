BloomBudget Interactive — Expanded Testing Build

Tech: HTML + CSS + JavaScript only. Data: browser LocalStorage.

TESTING MODE
- Login is bypassed for testing.
- Landing page provides direct User Mode and Admin Mode.
- Demo accounts are recreated automatically if missing.

USER FEATURES
- Dashboard with KPI cards, financial score, smart insights, savings goals, recent activity.
- Interactive spending pie chart.
- Income vs Expense chart with selectable 1–12 month range.
- Transactions with filters, search, sorting, category management.
- Budgets and savings goals.
- Analytics and needs-vs-wants.
- Financial planner/calendar.
- Finance tools: EMI, compound interest, emergency fund, 50/30/20, net worth.
- Money Center: recurring bills, subscriptions, debt/loan tracking, investments, expected income, forecast, alerts, monthly report and CSV export.
- Local backup/reset.
- Dark/light theme and interactive accent color.

ADMIN FEATURES
- Admin overview and system health.
- User management: block/unblock/delete.
- All-transaction search/filter and CSV export.
- System analytics.
- System monitor and data integrity checks.
- Operations Center: user directory search, announcements, audit log, category manager, full backup, demo-data generator, reset demo data, system rules.
- Accent color controls.

IMPORTANT
This is a frontend/localStorage academic demonstration. It is not production financial software and does not provide real banking/security services.
